# .agents/templates/

This directory contains reusable prompt fragments, document templates, and workflow patterns for developers and AI agents.

## Available Templates

- `context-template.md`: Template for long-term project context (`PROJECT_CONTEXT.md`).
- `handoff-template.md`: Template for active session state (`AI_HANDOFF.md`).
- `plan-template.md`: Template for multi-step task and feature plans.
- `commit-template.md`: Template for Conventional Commit messages.
- `pull-request-template.md`: Template for GitHub pull request descriptions.
- `ansible-role-readme-template.md`: Standard documentation template for Ansible role READMEs.
- `ansible-role-skeleton.md`: Starter snippets for Ansible role defaults, tasks, handlers, playbooks, and `Makefile` targets.
- `terraform-module-readme-template.md`: Standard documentation template for Terraform module READMEs.
