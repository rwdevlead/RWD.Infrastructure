# .agents/ — Project Agent Configuration

This directory contains the project-owned AI operating framework for `RWD.Infrastructure`:

- `standards/`: Mandatory coding, IaC (`ansible-standards.md`, `terraform-standards.md`, `shared-config-standards.md`), workflow, git/PR, and documentation standards.
- `templates/`: Reusable templates for plans, commits, PRs, memory/handoffs, Ansible roles, and Terraform modules.
- `skills/`: Slash-command skills for development, IaC scaffolding, auditing, and release workflows.
- `memory/`: Long-term project context (`PROJECT_CONTEXT.md`), active session handoff (`AI_HANDOFF.md`), and multi-step plans.
- `examples/`: Reference examples for plans, review verdicts, and custom skills.
